Four opt-in options for dense data screens. Drawer takes `stackNarrow`, passed to its header. A TrackTable column takes `width`, a fixed size from a size or space token name or a CSS length. FoldText takes `fill`, which contains the text width so a table cell does not widen, and `truncate="middle"`, which keeps the start and end of a string such as a path and shows the full text in a tip. TextInput takes `mono` for the monospace face, so a read only command line can grow beside Copy and Run buttons.
