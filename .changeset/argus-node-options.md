Eight opt-in options for the Argus Node design; every default look stays the same. Tabs takes `size="lg"` for 40 px tabs. SegmentedControl and a selectable Tag take `selectedTone="neutral"` for a grey selected fill instead of the accent. Tag takes `outlined` for an edge with no fill. DropdownMenu takes `itemSize="roomy"` for 13 px text and taller rows, which adds the `--size-13` and `--text-md` tokens. The `book` icon joins `robot` and `flask`. Markdown takes `smartTimes` to draw a multiplication sign for an x between two digits, as in 1920x1080.
