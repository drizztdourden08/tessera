`SplitButton` takes `iconOnly` and `shortcut`. With an `icon`, `iconOnly` draws the main button as the icon alone, and a tooltip shows the label and the shortcut. The label still names the button for assistive tools. `shortcut` takes keys such as `F3`, and it adds the same tooltip to a text button. It works with `pressed` and with a `panel` chevron. Without the two props nothing changes.
