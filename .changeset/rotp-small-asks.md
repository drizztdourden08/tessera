Small parts RotP asked for, so it can drop its own copies. The named icon set gains fifteen Lucide icons: shuffle, database, store, camera, joystick, smartphone, wrench, dices, list-checks, scroll-text, network, person-standing, languages, music and layout-dashboard. A tab takes `disabled` and `disabledReason`: it greys out, the arrow keys, Home and End skip it, and the reason shows as a tooltip and is read as its description. Disclosure takes a controlled `open` beside `defaultOpen`, with `onOpenChange`. ItemCard takes `navigate` for app routing, as Link does, and `mediaHeight="auto"` for a picture taller than the 96 px band. Tag takes `variant="custom"` with a hex `color` from app data, and picks black or white text, whichever reads best. A menu item icon, and a menu trigger icon, can be a name, iconify data, Icon path data or an element.
