Button has `fill="gradient"`, a vertical gradient with a soft primary glow for a call to action, and `width="wide"`, a minimum width so a lone button does not shrink to its label. At `lg` the flat label is bold, and a palette can set `--p-primary-gradient-from` to keep the label readable on the lighter end.
