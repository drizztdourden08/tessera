Anchored pins a popup to its trigger through the browser's popover top layer and CSS anchor positioning, so it follows the trigger in the same frame as a scroll. Select, Combobox, TagInput, Tooltip, DropdownMenu, ColorPickerPopover, the Widget settings and the FilterBar and DataTable menus use it, with the script placement as a fallback.
