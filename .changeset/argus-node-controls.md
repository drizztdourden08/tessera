Nine more opt-in options for the Argus Node design; every default look stays the same. DropdownMenu takes an item `kind="select"` with `options`, `selected` and `onPick` for a labelled Select row beside the action rows, which keeps the menu open and the arrow keys working. Markdown takes `linkTone` to draw links, including id links, in the text colour with `neutral`. DataTable `rowState` takes `edge` for a left bar with no tint. Link takes `tone="info"`, underlined in the info colour. Disclosure takes `wrapEnd` to drop the end slot under the summary below 384 px, which adds the `--disclosure-wrap` token. Tabs takes `selectedTone="neutral"` for the active label in the text colour. TagPicker takes `pill` for round chips. Tag takes `size="lg"` for 24 px. Text takes `size="md"` for the 13 px step.
