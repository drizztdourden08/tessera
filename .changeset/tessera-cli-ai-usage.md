Tessera now ships an `ai/` folder: a decision tree, the always-rules and one page per component, generated from each component's usage file by `pnpm ai`, for any AI working in an app that uses Tessera. The new `tessera new <kind> <Name>` command creates a primitive or composite in Tessera, or a compound, view, primitive or composite in an app, with its usage file and gallery story. The human guides in `docs/` ship with the package.
