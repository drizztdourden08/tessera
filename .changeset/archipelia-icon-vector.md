The Archipelia mark is redrawn as a clean vector of true circles and straight bars, with the same look, so its edges stay smooth at any size and every brand file is regenerated from it. BrandMark, Logo, Logo.Combined, Mascot and AnimatedMascot take a new `xxl` size, the 256 px token `--brand-mark-xxl`, for a large mark such as an empty start page.
