# Tessera usage guide

This folder tells a reader, a person or an assistant, which `@drizztdourden08/tessera` component fits a case and how to use it. `pnpm guide` builds it from the usage file beside each component and from the code itself, so edit those, not this folder.

Read in this order:

1. [rules.md](rules.md): the rules that hold on every screen.
2. [decide.md](decide.md): questions that lead from what you are placing to the component for it.
3. [index.md](index.md): every component on one line, with where to import it from.
4. `components/<Name>.md`: one page per component, with its rules, an example and its props.
5. [registry.json](registry.json): the same facts as data.

43 of 171 components have their usage written. A component without one is listed in the index with its import path only.
