## Tessera should adopt

From the rows above. Nothing here changes a component yet.

- The Escape stack by level: dialogs and screens join the popup stack, a key an inner editor handled is left alone, and an app shortcut can ask the depth. One press then closes one thing whatever mounted first.
- `min-width: 0` on an inline Field's control, so a narrow inline row stops running past its box.
- The lift for a flipped ColorPickerPopover on the fallback path, so it opens above its swatch and not over it.
- `2xs` in `SpaceToken`, so Flex, Grid and Spacer reach the 2 px step the tokens already have.
- The working record as a third argument to `IdRefOptionResolver`, so a reference can narrow by a sibling field.
- `fieldRenderers` on CompactRecordView, so an app draws one field its own way without losing its place.
- The group heading of CompactRecordView in the secondary accent, so a scan tells a heading from a field label.
- The hex text of a formatted number as its editor hint, so the editor reads like the cell.
- `{ value, label }` options in `SchemaConfig.options`, so a declared set shows names and keeps numbers as numbers.
- A measured fit for the enum editor, falling back to a searchable Select, so long labels never push past the row.
- DropZone media types, a status line and Ctrl+V paste, so a picture or a pack is checked and taken in place.
- A red outline on Checkbox and DropZone inside an erroring Field, so every control shows the error, not only text fields.
- `min(100%, N)` in Grid's `minColWidth` columns, so a single cell fits a box narrower than the minimum.
- A one line plain label on Button, so a tight row moves the button and does not break its words.
