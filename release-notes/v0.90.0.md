# Tessera v0.90.0

This release moves the DockLayout corner turn into the seam, so it no longer covers widget content, and gives VirtualGrid a fixed column count for tilesets.

## New

- VirtualGrid takes `columns`, a fixed number of tiles per row. Keys, ranges, the marquee, reorder and sections follow it, and a narrow grid scrolls sideways instead of shrinking the tiles.

## Fixes

- The DockLayout corner turn is now the end of the seam divider: drag across the seam at a panel corner to turn it. Nothing sits over widget content or title bar buttons, so apps can drop any padding they added for the old handle.
- The keyboard corner control keeps its tab stop, arrow keys and status message, and has no pointer box, so it passes the target size check.
