# Tessera v0.58.1

This patch fixes two DynamicInput behaviours that came with the slot character rules.

## Fixes

- A key a slot does not allow is ignored. Focus moves to the next slot only for the pattern's own separator or when the slot is full.
- A partly filled text slot keeps what was typed when it loses focus, and is marked invalid. A slot with a fixed or minimum length shows a built-in message when it is incomplete.
