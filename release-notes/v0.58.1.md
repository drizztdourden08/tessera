# Tessera v0.58.1

One paragraph for the people who use Tessera: what this release changes for them.

## Fixes

- DynamicInput ignores a key the slot does not accept, and moves on only at the literal separator of the pattern or when the slot is full. A partly filled text slot keeps what was typed when it loses focus and shows an incomplete message instead of being cleared.
