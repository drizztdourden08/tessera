# Tessera v0.36.0

This release makes screens calmer and clearer: informational windows open small, animated parts no longer push their neighbours around, and only the title bar's main menu button turns into an X. It also adds sunken and raised panels, always-visible On and Off explanations on settings toggles, and fixes a dropped file opening in place of the app.

## New

- Box takes `surface`, `sunken` or `raised`, for a well set into the page or a panel lifted off it. Code blocks, the colour picker, pressed grids, record editor items, the list side of ListDetailLayout and ShortcutTour now draw on it, with the same look.
- A settings toggle takes `hints: { on, off, atRest: true }` to show both its On and Off lines at all times, each after its gold label, with the current state's line brighter.
- Button takes `hint`, as IconButton does, so it reports its hint to the HintScope around it without a wrapper.
- ScreenLayer and ScreenWindow take `size="info"` for a small centred card sized to its content.
- A new `--ease-out` motion curve.

## Changes

- Informational windows open small: InfoScreen is a centred card at most 512 px wide that scrolls only when the window is too short for it.
- The title bar's main menu button turns from the hamburger into an X and back in 200 ms, at once with reduced motion. Every other menu button keeps its three bars while its menu is open.

## Upgrading

- InfoScreen no longer takes `width`, and the `InfoScreenWidth` type is gone.
- A DropdownMenu trigger with only the hamburger icon, including the SiteHeader phone menu, no longer turns into an X when open; change the trigger icon from `onOpenChange` to show something else.
- MIGRATION.md sections 229 to 235 describe each change.

## Fixes

- A file dropped on a disabled DropZone, or on a disabled or read only PathInput, is caught with the not allowed pointer, so the app window no longer opens the file.
- A title bar status that counts, such as a frame rate, keeps its width as its digits change, so the items beside it stay put.
- A long tooltip, such as the reason on a disabled tab, wraps inside its box instead of running past it.
