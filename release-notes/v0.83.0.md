# Tessera v0.83.0

This release makes FoldText public, so an app can clamp text to a few lines with the same control FormRow and SettingsRow use.

## New

- FoldText is a public primitive. It clamps text to `lines` lines, and `overflow` picks what happens past them.
- `more` adds a More and Less control, `hint` keeps the height and shows the full text in a tip, and `clip` cuts the text with no control.
- The control and the tip only show when the text runs past the lines.
- The package exports `FoldText`, `FoldTextProps` and `FoldOverflow`.
