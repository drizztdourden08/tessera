# Tessera v0.131.1

String functions now take text ready to show and keep names as written, so translations work.

## New

- `common.copy`, the Copy label with no name.

## Changes

- `scrubRuler.valueText` takes the 1-based frame number.
- `lists.filterOf`, `lists.loadingOf`, `lists.loadFailed`, `items.confirmAgain` and `widgets.moveMainHint` keep the name as written.
- `items.confirmAgain` reads "Click again: " and the label.
