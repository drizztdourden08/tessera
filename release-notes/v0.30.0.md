# Tessera v0.30.0

One paragraph for the people who use Tessera: what this release changes for them.

## Changes

- ResizeHandle is the one line SplitPane, ListDetailLayout, DockLayout and the DataTable column resize all draw, with the arrow keys, Home, End and Enter, its value and range, and `edge` for a panel after the line; `usePaneSize` keeps a panel width in pixels. Grid takes `dense`, and `Grid.Cell` spans two columns once two fit or the whole row, for a dashboard of Cards.
- SiteHeader and SiteFooter frame a website built from the app's parts: SiteHeader holds the logo and the site title as the link home, main links that fold into one menu under 640 px and the signed-in person drawn with WindowTitleBar's own dropdown action; SiteFooter is a small line with the logo, a note and links.

## Fixes

- The package ships `release-notes/`, one hand-written note per version from 0.29.0 on, which is also the body of each GitHub release.
- The GuidedTour spotlight measures again once the fonts are ready and after each step's onEnter settles, so one step lands on the same pixels on every load. LogPanel time cells, the RetryButton countdown and the StickPlot dot, stem and readout carry `data-review-mask`, exported as `REVIEW_MASK_ATTRIBUTE`.
