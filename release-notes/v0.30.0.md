# Tessera v0.30.0

A website can now be built from the same parts as an app, with only a header band and a footer of its own, and every pane you can drag wider shares one resize line that also works from the keyboard.

## New

- SiteHeader is the band at the top of a website: the logo and site title link home, the main links fold into one menu button on a phone, and the signed-in person shows with the same button the app's title bar uses.
- SiteFooter is the small line at the foot of a website, with the logo, a short note and links.
- The SiteHeader page shows how to build the rest of a site from the app's own parts, including a sign-in card on the brand gradient in both its dark and light colours.
- ResizeHandle is the one line you drag to resize a pane. It works with the arrow keys, Home, End and Enter, tells screen readers its value and range, and can sit after a panel with `edge="end"`.
- `usePaneSize` keeps a pane's width in pixels and can remember it between visits.
- Grid takes `dense` to pack cards tightly, and `Grid.Cell` can span two columns once two fit, or the whole row, so a dashboard needs no part of its own.
- `REVIEW_MASK_ATTRIBUTE` marks a value that changes on every run, so a screenshot check can ignore it.

## Changes

- SplitPane, ListDetailLayout, DockLayout and the DataTable column resize all draw ResizeHandle. They look the same as before, and the dock and table lines can now be reached with Tab and moved with the keys.
- LogPanel times, the RetryButton countdown and the StickPlot dot and readout carry the review mark.
- The package now includes these release notes, one per version from 0.29.0 on.

## Upgrading

- The classes `split-pane__divider`, `split-pane__grip`, the `dock-divider` variants and `data-table__resize--active`, and the token `--dock-divider-bar`, have new names. RENAMES.json maps each one, and the token is now `--resize-handle-bar`.
- MIGRATION.md sections 212 to 214 describe each change.

## Fixes

- The guided tour spotlight measures again once fonts have loaded and after each step's preparation, so a step lands in exactly the same place on every load.
