# Tessera v0.43.0

Windows can drop their title row for more room, with a corner X and a lock that lets the user move and resize them. Side panels follow one standard, list rows line up with buttons, and new press-twice buttons load, save or delete with an icon that keeps moving until confirmed.

## New

- ScreenWindow takes `titleRow={false}` for a small round X on the card's corner, and `movable` for a lock beside it. Locked, the window is centred with smaller gaps; unlocked, it moves by its top edge and resizes from its edges and corners, and `storageKey` remembers where.
- ArmedIconButton is pressed twice to confirm: the first press arms it and its icon loops (load lifts, save sinks, delete lifts its lid). The `load-state` and `save-state` icons join the icon set.
- ItemList rows take a flush `media` picture and `renameInline`, which edits the name in place from a pen shown on hover.
- WindowTitleBar's revealed bar has its own `--z-title-bar` layer above docked and floating widgets.

## Changes

- SidePanel is the one side panel standard: a sunken body, an edge line with the fold button level with the heading, and a 60 px folded rail showing its actions, its title written sideways and its item icons, with nothing clipped.
- List rows in every list start at the same inset as a Button's content, compact rows included.
- A Select's highlighted option fills the whole row, and the trigger and the open list read as one shape.
- VolumeIcon has four steps whose waves grow taller with the level; the waves use the primary colour, the speaker is white and the mute X is red.
- Windows without a title row have tighter padding inside, with 8 px between the switcher and the content.

## Upgrading

- DockLayout's resize classes `dock-resize*` are now `rect-resize*`; RENAMES.json maps them.
- MIGRATION.md sections 260 to 265 describe each change.

## Fixes

- The title bar's peek takes Escape alone, so the app no longer acts on the same key.
