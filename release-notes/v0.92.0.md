# Tessera v0.92.0

One paragraph for the people who use Tessera: what this release changes for them.

## Changes

- `BrandMark` and `Logo` take `fit="height"`, which makes `size` the height of the mark and lets the width follow the mark's own shape, so a wide mark such as Argus's is no longer shrunk into a square. Two new sizes, `h26` and `h39`, are 26 and 39 px tall; the default `fit="square"` is unchanged. A new scale token, `--size-22`, is 22 px.
- The Brock and Tessera marks are redrawn from their traces as clean vectors with the same look: Brock's stone facets meet at exact corners, and Tessera's mosaic tiles have straight edges with exact or softly rounded corners, so neither shows jagged edges at large sizes. Every Brock and Tessera brand file is regenerated from them.
- Every component folder has an import path of its own: `@drizztdourden08/tessera/primitives/Button` and `@drizztdourden08/tessera/composites/DataTable`, and the same for a group barrel such as `/primitives/layout-exports` or a kit such as `/composites/selection`. A test file or a small module that imports one component loads that component and what it uses, not the roughly 5000 modules of the full barrel. `KeyboardLayout`, `LogPanel`, `ShortcutTour` and `SplitPane` import their primitives from the primitive folders instead of the primitives barrel, so each loads fewer modules. The existing import paths work as before.
