# Tessera v0.92.0

This release lets apps import one component at a time, sizes wide brand marks by height, and ships the cleaned Brock and Tessera marks.

## New

- Every component folder has its own import path, such as `@drizztdourden08/tessera/primitives/Button` or `@drizztdourden08/tessera/composites/DataTable`. A Button import loads about 350 modules instead of the 4,250 of the whole package. Every existing import path still works.
- BrandMark and Logo take `fit="height"`: `size` sets the height and the width follows the mark, so a wide mark such as Argus's keeps its shape. New sizes `h26` and `h39` match 26 and 39 px headers.
- New size token `--size-22`.

## Changes

- The Brock and Tessera marks are redrawn as clean vectors with the same look, without the wobble of the old traces.
- SplitPane, KeyboardLayout, ShortcutTour and LogPanel import only the primitives they use, so they load far fewer modules.
