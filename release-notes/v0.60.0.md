# Tessera v0.60.0

One paragraph for the people who use Tessera: what this release changes for them.

## Changes

- Grid takes `fit` with `minColWidth`: empty column tracks collapse, so a lone child or a short row fills the width instead of one column of it.

## Fixes

- ControllerSilhouette anchors and sizes now follow measured real pads. Anchor ids are unchanged.
