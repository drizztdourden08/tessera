# Tessera v0.81.0

This release answers a round of Argus and Archipelia requests. Tags, badges, cards, list rows and headers gain small layout options, Callout gains a title, and a guided tour can now light an entry of an open menu.

## New

- Tag takes `pill` for a fully rounded shape, `icon` for a leading icon, and `href` with `navigate` or `onClick` to render as a link that keeps its chip look.
- Badge takes `icon` to lead a count with an icon. Status takes `size="sm"`, a row 18 px tall.
- DataTable `rowState` takes `'fresh'`, a soft info tint for new rows. DataTable takes `headerCase="upper"` for capital column labels.
- ContentHeader takes `variant="plain"`, a title row with no backdrop, gradient or border. PageFrame takes `padding="md"` for 16 px of page padding.
- SectionHeader takes `size="lg"` for a larger title and `wrap` so a long title wraps with its count inline.
- Card takes `flush`: no body padding, so a table or a list runs edge to edge inside the border.
- ListItemRow takes `lead`, an id or a code before the name, and `flat`, a dense row with no fill until hover or selection.
- Disclosure takes `end`, a slot at the right of the summary that never toggles it. InlineCreateForm takes `dashed`.
- Callout takes a `title`, a bold first line above the text, so a banner is a Callout with a title.
- New `flask`, `robot` and `git-branch` icons.

## Fixes

- GuidedTour now sits in the browser top layer and stays above open menus, so a tour step can light a DropdownMenu entry and a click on it reaches the menu.
