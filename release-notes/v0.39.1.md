# Tessera v0.39.1

A studio's toolbar can now be a single compact row of tools, so the editor below it gets more height.

## New

- ToolGroups takes `compact`, and StudioLayout takes `compactToolbar`: the groups sit in one row with a line between them and no visible labels, and the controls inside draw at the compact size. Screen readers still hear each group's name. The studio toolbar drops from 65 to 45 px.

## Upgrading

- MIGRATION.md section 254 describes the option and replaces the advice in section 253 to wrap each group in DensityScope.
