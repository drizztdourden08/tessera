# Tessera v0.48.0

SideNav items can now carry a badge, so a window with a side nav can show a count beside a section, such as unread items.

## New

- Add `badge` to SideNav items. A number or text becomes a count pill at the end of the row. Any other node is drawn as given.
- When the nav is collapsed to its icons, the row shows a dot over the icon instead of the pill.
