# Tessera v0.85.0

This release adds a few more opt-in options for the Argus Node design and for dense data screens. Every default look stays the same.

## New

- Select, Combobox, TextInput and SearchInput take `width="narrow-fill"`: 220 px, and the full row when the container is under 420 px.
- Tabs takes `badgeFill="solid"` for solid count badges with dark text.
- Tag and Status take a `reason`, drawn in the tone after a name in the text colour, for a fault chip.
- Markdown takes `idLinkTone`, so links to ids such as T-12 can take their own tone apart from web links.
- Drawer takes `stackNarrow`, passed to its header.
- A TrackTable column takes `width`, a fixed size from a token name or a CSS length.
- FoldText takes `fill`, so a table cell holding it does not widen, and `truncate="middle"` to keep both ends of a path.
- TextInput takes `mono`. With `readOnly` and a ButtonRow `lead`, it makes a command line that grows beside its buttons.
