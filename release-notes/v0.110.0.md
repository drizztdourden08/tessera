# Tessera v0.110.0

This release lets a FilterBar field limit its operators and adds two small slots.

## Changes

- A FieldDescriptor can name its allowed operators, and the FilterBar chip menu then offers only those, in that order, with new clauses starting on the first one.
- FilterBar takes a leading element that sits before the clause chips in the same row.
- Select takes a prefix label shown in muted text before the value, so a trigger can read "Focus: X".
