# Tessera v0.104.0

OptionRow now folds a long description and gives reset its own place.

## Changes

- OptionRow folds its description at two lines, with the full text on hover, like FormRow. New props `descriptionLines` and `descriptionOverflow` set the fold.
- OptionRow shows the reset button in its own cell after the control when the row is changed and has `onReset`, so it no longer crowds the control.
