# Tessera v0.131.0

Locale control, named string params, right to left layouts and three new icons.

## New

- `TesseraOverrides.locale` and the `useTesseraLocale` hook set the locale of every date, number and size.
- `TESSERA_STRING_PARAMS` and `TesseraStringParams` name the params of every function string.
- Strings `colorPicker.hex` and `panels.contents`.
- Icons `cartridge`, `patch` and `bandage`.
- A right to left story in the catalogue.

## Changes

- Every `Intl` call takes the locale.
- Yes and No in list values come from `common.yes` and `common.no`.
- Component CSS uses logical inline properties, so layouts flip with `dir="rtl"`.
