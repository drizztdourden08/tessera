# Tessera v0.40.0

An app now has one Ctrl+Z: deletes in a list and actions offered with Undo in a toast go on the same undo stack. A list's New button can also be switched off with a reason instead of being hidden.

## New

- `useUndo` gives the whole app one undo stack. Ctrl or Cmd+Z undoes the latest step, never while typing in a field, and a step can be limited to a region of the page.
- `toast({ undo })` draws an Undo button and puts the step on the stack while the toast shows; once the toast is gone, the step is gone too.
- ItemList and ListDetail take `newDisabled`, with a reason shown on hover and focus, the same way as other switched-off choices.

## Changes

- ItemList deletes with `undoDelete` now go on the shared undo stack.
- A button marked `aria-disabled` now looks switched off.

## Upgrading

- The `lists.undo` string is now `common.undo`; RENAMES.json maps it.
- MIGRATION.md section 255 describes each change.
