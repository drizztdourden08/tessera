# Tessera v0.39.0

This release adds DateText, one part for showing a date or a time in any format, and makes the studio layout and toolbar inputs fit real screens: StudioLayout stays side by side next to a list, and a search box sits on one line with the other tools.

## New

- DateText shows a date or a time as relative ("5 minutes ago"), calendar ("Today, 21:40"), date, time, date and time, weekday, month, ISO or any Intl options, in three lengths, with the full date on hover. Relative and calendar times update by themselves without changing width, and their words come from the strings, so they can be translated.
- `formatDate` gives the same formats to code, DataTable takes date columns through `dates`, and Select and Combobox columns accept every date format.
- SearchInput, Select and Combobox take `grow={false}` to keep a set width that can shrink, so they sit on one line with the other tools in a toolbar.
- StudioLayout takes `editorMinWidth`.

## Changes

- StudioLayout stacks its columns only when the open panels, the folded rails and the editor's minimum width don't fit side by side, in place of a fixed 768 px, so it stays side by side next to a list on an ordinary window.

- MIGRATION.md sections 252 and 253 describe each change, including how to replace a hand-made relative time and a hand-made studio body.
