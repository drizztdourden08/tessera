# Tessera v0.89.0

This release finishes the Bxel redesign asks with the tree family, fixes what Bxel's palette widget found, and adds two SeatCard states for Archipelia's lobby. Every new option is opt-in.

## New

- `Tree` is a virtual tree of any depth with APG keys, type ahead, single or multiple selection, lazy children and a filter.
- Tree rows reorder by drag or by Alt and an arrow key, with a gap line, an into mark, a DragGhost, `maxDepth` and `canDrop`.
- GroupTree is rebuilt on Tree with the same props and behaviour. Its rows now sit at a fixed 28 px stride.
- New MillerColumns: columns of lists over one shared selection, with an app-owned path.
- `useToggleSweep`: press a toggle and drag over the others to set them all, committed once at the end.
- InlineEdit takes `dense` for a 24 px row, with the error line beside the field.
- Slider takes `trackBackground`, so a channel gradient is the track itself.
- ColorSwatch `marks` also take an object keyed by corner name, the marks scale with the swatch, and `size="xs"` fits a menu icon.
- SeatCard takes `selected` on filled and attention seats, and `state="held"` for a reserved seat waiting for its player.

## Fixes

- Holding Alt no longer remounts a docked widget's content, so focus stays and Alt with an arrow key reaches the control.
- Tooltip draws its bubble in the tooltip layer, outside its anchor, so a Tooltip on a listbox option passes the accessibility check.
- ColorPicker's current colour swatch has an accessible name.
- Slider thumbs have a 24 px hit area at every size, with the same drawn size.
