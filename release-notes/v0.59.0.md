# Tessera v0.59.0

This release grows VirtualGrid into a full browser for large sets of tiles: folders, drag selection, jumping to an item and tiles of any shape. Bxel's older file format gets its own icon.

## New

- VirtualGrid takes `sections` in place of `items`, with a collapsible header row over each section. `collapsed`, `defaultCollapsed` and `onToggleSection` control it, and the keys move between headers and tiles.
- VirtualGrid takes a `ref` with `scrollToIndex(index, align)`. An item in a collapsed section scrolls to its header.
- A file icon for Bxel's older `.bxel` format: an archive box on the usual document page, with the new `pixel-legacy` icon.

## Changes

- VirtualGrid works with drag selection: `scrollRef`, `bind` and `overlay` hook up `useMarqueeSelect`, and every tile carries `data-marquee-key`. Only the tiles in view can be picked, since the grid draws the rows in view.
- VirtualGrid takes `tileWidth` and `tileHeight` for tiles that are not square. `tileSize` stays the square shorthand.
- `useVirtualWindow` takes `readMetrics` and `rangeOf` for rows of more than one height, and `scrollTopForSpan` gives the scroll offset of any row.
