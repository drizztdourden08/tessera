# Tessera v0.109.0

This release adds view controls, an icon picker, palette motion and a glass surface.

## Changes

- ViewControls is a collapsible row that holds a FilterBar, a GroupControl and a SortControl, with a count of active choices when it is closed.
- GroupControl is a menu that groups a collection by one field, and SortControl sorts by one field with a button that flips the direction.
- IconPicker lets the user pick a family icon from a searchable grid or upload an SVG or PNG file, with size limits.
- The useSwitchPalette hook cross-fades a palette change, and the paletteTransition override turns the fade off.
- ContentSwap is a new primitive that fades, slides or scales from old content to new content when its key changes.
- Card, PanelContainer, Dialog and DialogShell take surface="glass" for a blurred, see-through panel that turns solid under reduced transparency.
