# Tessera v0.56.1

One paragraph for the people who use Tessera: what this release changes for them.

## Fixes

- ListDetailLayout with both panes collapsible now spaces the two seam buttons apart, each on its own pane edge, and the detail draws the same dashed fold line as the list. A folded detail no longer hides half of its unfold button behind the rail.
