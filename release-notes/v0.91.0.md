# Tessera v0.91.0

This release answers more of Bxel's drawing and sheet asks: toolbar groups that fold as one, new ink icons, a brush picker recipe, Tile media shapes and native drops. Every new option is opt-in.

## New

- A Toolbar separator takes `priority`. The items after it, up to the next separator, fold into More together under its heading, so a group never splits between the bar and More.
- New pixel icons: `pixel-ink-replace`, `pixel-ink-blend` and `pixel-symmetry-badge`.
- A brush or pattern picker is a recipe: a Toolbar popover that holds a ChoiceGrid of pixelated previews, with an add action in its footer. The ChoiceGrid usage and a Toolbar story show it.
- Tile takes `mediaAspect`, such as `4/3`, `16/9` or a number. The default stays square.
- A VirtualGrid section takes `onDropData` and `accepts`, so its header takes native drops such as files without turning on reorder.
- `useNativeDragGhost` draws a DragGhost with a count as the drag image of a native drag.

## Changes

- The primitives barrel is split into group barrels, one per gallery group. Every export is unchanged, and `tessera new primitive` writes to the group barrel.
