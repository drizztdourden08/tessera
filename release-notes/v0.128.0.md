# Tessera v0.128.0

Pieces asked for by Argus for its paired plan and run view.

## New

- PairedTree shows N trees side by side on one row axis. A row missing in a column shows a faint ghost cell, and a row tone marks it running or done.
- Icons corner-down-right, more-vertical and loader.

## Changes

- Text takes indent, a tree depth from 0 to 8. Pair it with as="div".
- TableRow takes tone: accent, success, warning, danger or info.
- TableCell takes width: auto, xs, sm, md, lg or fill. Set it on the header cell.
- New tokens --indent-step, --indent-1 to --indent-8 and --column-xs to --column-lg.
