# Tessera v0.78.0

This release stops a page from flipping its columns as its scrollbar comes and goes, makes the guided tour settle in bounded time, and adds a gradient call to action, draggable list rows and base64 images in Markdown.

## Changes

- Button has `fill="gradient"`, a vertical gradient with a soft primary glow for a call to action, and `width="wide"`, a minimum width so a lone button does not shrink to its label. At `lg` the flat label is bold, and a palette can set `--p-primary-gradient-from` to keep the label readable on the lighter end.
- ListItemRow takes `draggable` with `onDragStart` and `onDragEnd`, so a whole row can be dragged onto an app drop target.
- Markdown with `images` on also draws base64 png, jpeg, gif and webp images (never svg), and has an `onImage` callback that turns each drawn image into a button for a lightbox. It also strips control, private-use and lone surrogate characters from the source before parsing.

## Fixes

- ScreenPage and SideNavLayout content keep a stable scrollbar gutter, so a page whose layout reflows with width no longer flips as the scrollbar comes and goes.
- ScrollArea takes `gutter="stable"` so a page body that reflows with width cannot flip its columns as its scrollbar comes and goes, and GuidedTour settles in bounded time at any frame rate, with a mascot walk timed by the clock and a stand that ignores small changes.
