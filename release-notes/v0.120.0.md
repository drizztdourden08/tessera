# Tessera v0.120.0

A new Flex alignment asked for by Argus.

## Changes

- Flex takes align first-line, which centres an icon or another small piece on the first line of text beside it, even when the text wraps.
- It matches the size of the Text beside it, so the icon stays centred for caption, subtitle, body and title text.
- The Flex story has a new variant that shows an icon beside wrapping text at four sizes.
