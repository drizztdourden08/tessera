# Tessera v0.37.0

This release brings a three-column studio layout built entirely from shared parts, a size setting for Hero, and a set of fixes Relic of the Past needed before its next round of testing: evenly spaced buttons with an icon, header chips that never wrap, a title bar that can't be selected by accident and fact values on the right edge.

## New

- StudioLayout lays out a work screen in three columns, a list, an editor and an inspector, under a raised bar with grouped actions and a hint line. Its side panels fold to a rail and can be resized, and the columns stack when the layout is narrow.
- Three shared parts StudioLayout is built from, for any screen: SidePanel, a panel with a heading that folds and resizes; ToolFrame, a sunken frame with its toolbar on the top edge; and ToolGroups, labelled groups of actions.
- Hero takes `size`: `compact` follows its content, `default` keeps today's look, and `tall` is taller.
- BackdropLayer and `backdropStyle` draw a picture, a colour or a scene behind any block, as Hero does.
- FactsPanel and StatRow take `align="end"` to put each value on the right edge.

## Changes

- A Button with an icon has the same padding on both sides, and an icon with no size of its own takes the button's size (16, 14 or 12 px). Buttons with an icon are 4 px narrower; heights are unchanged.
- The title bar, window and dialog headers, widget title strips and menus can no longer be selected by accident; inputs inside them still work.
- Header chips never wrap. The row scrolls sideways, with the plain mouse wheel too, shows arrows only when chips are hidden, and moves under the title when there is no room beside it. The title keeps its full width.
- ListDetailLayout and LogPanel are drawn from the new shared parts, with the same look.

## Upgrading

- `HeroBackdrop` and `HeroImageFit` are now `Backdrop` and `BackdropFit` in the primitives; RENAMES.json maps them and the backdrop classes.
- ListDetailLayout's rail label class is now `pane-rail__label`, and LogPanel's `log-panel__toolbar` class is gone.
- MIGRATION.md sections 236 to 239 describe each change, including how to replace a hand-made studio frame with StudioLayout.
