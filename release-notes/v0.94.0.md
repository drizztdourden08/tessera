# Tessera v0.94.0

This release answers Bxel's sheet and map asks: rows that join typed drags, tiles that read in order, a drag select that leaves menus alone, and the tile map icons.

## New

- DataTable takes `rowRef(row, key)`, which hands the app a ref to each drawn row, so a row can be a typed drag source of the host. It attaches and releases as virtual rows scroll in and out.
- The pixel icon `pixel-map-stamp-capture` is now `pixel-stamp-capture`, and `pixel-map-wand` is redrawn with a clear wand over a group of picked cells.

## Fixes

- A drag select from `useMarqueeSelect` starts only from a press inside its box and outside any menu, dialog, listbox or tooltip in it, so a ContextMenu opened from a tile keeps its click.
- Tile puts its name before its corner slots in the reading order, so a count badge reads after the name. The look is unchanged.
