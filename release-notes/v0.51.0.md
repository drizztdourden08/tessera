# Tessera v0.51.0

Two new parts for editor apps, a reorderable list and a status bar, and two fixes. The ScreenWindow corner title is a true pill again, and ListDetail shows its list count again.

## New

- New composite ReorderList. It is a list the user puts in order by dragging the grip or with the keys, with a row of on and off icons on each item, such as visible and locked for the layers of a drawing. Describe the icons once in `toggles`, keep each item's state in its own `toggles`, and flip it in `onToggle`. Each icon is a button named by its label with aria-pressed. Arrow keys, Home and End move focus, Space or Enter selects, and Alt with Up or Down moves the row. Moves are announced.
- New composite StatusBar, the thin bar at the foot of an editor window. It shows labelled readouts such as cursor position, zoom, current colour, sprite size, layer and frame. Each item has a label and a value, and can take an icon, a colour swatch, a tone and a hover title. Numbers use tabular figures, so a cursor position does not jitter. On a narrow bar, items with a priority drop out, 3 first. The bar is not a live region, so a moving cursor is never announced.

## Changes

- The drag and the keyboard step of RowGrid now come from one shared reorder folder, which also handles horizontal lists. RowGrid looks and behaves as before.
- ItemList takes an optional `onCount(shown, total)`, which reports its shown and total counts.

## Fixes

- ListDetail shows the list count in its panel heading again, as it did before 0.46.0.
- The ScreenWindow corner title is a true pill again, aligned on the line of the close and lock buttons.
