# Tessera v0.57.0

This release adds 48 pixel art icons for drawing apps and lets toolbars hold any icon an app draws itself.

## New

- 48 pixel icons on the 24 by 24 grid, in the style of the tool icons: brushes, canvas view (grid, tiled, rulers, onion skin, mirrors), file actions (undo, redo, save, export, layers, palette, lock), sheet views, tilemap tools, sprite transforms, timeline playback and frame actions. Names start with `pixel-`, for example `pixel-brush-square` and `pixel-map-fill`.
- `useHoverOpen` and `HoverOpenParams` are public, so an app can open a menu on hover from its own buttons.

## Changes

- Toolbar items take an icon name or any node as `icon`, in the bar and in More, so an app can place its own drawings in a toolbar.

## Under the hood

- Tessera uses brock-thread 0.87.1, which accepts the same standards version, so the standards override is gone.
