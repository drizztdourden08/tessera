# Tessera v0.63.0

This release finishes the accessibility fixes of the document tabs and the stepper, lets drag selection reach every tile of a long grid, and rounds out the compact card for large catalogues.

## New

- The VirtualGrid ref handle has `getRects()`. It gives the rect of every item from the layout, not only the drawn ones, so `useMarqueeSelect({ getRects })` selects tiles out of view. Items in collapsed sections are left out.
- VirtualGrid section headers take `actions`, drawn as icon buttons at the header end, and `depth`, which indents nested sections.
- ActionItem takes `loading` and `nameSuffix`, which makes each row's button name unique, such as "Remove" followed by the item's name. `confirm: false` skips the inline ask, for an app that asks with its own dialog; danger actions still ask by default.

## Changes

- A compact ItemCard shows its `tags` on a line of their own, cut with a +N tag when they do not fit. `details` takes nodes, so a status can carry a Tooltip.
- ItemCard takes `mediaLabel` to name a meaningful media tile, and `mediaTone` takes `'tertiary'`.

## Fixes

- DocumentTabs keeps a real tablist that holds only its tabs. The close buttons sit in a layer of their own over each tab's end, so tablist and tab lookups work and nothing uses aria-owns.
- Each Stepper step is named exactly as it reads: its number, label and summary. Done or needs attention is a description.
- MIGRATION.md and RENAMES.json point past Brock 0.96.0, which retired CalibrationPanel: calibration is in the Controllers hub, and a pad is drawn with ControllerSilhouette or PadOverlay.
