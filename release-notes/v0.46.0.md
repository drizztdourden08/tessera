# Tessera v0.46.0

Collapsible panels now share a consistent title, folded rail and resize edge. Expanded panel content is grouped under visible primary-color headings, and the list pane follows the same layout. Compact windows use the available space more fully, while move and resize guides stay clear without dimming the app.

## New

- `PanelContainer` groups panel content under a primary-color title and optional action.
- `SidePanel` and the list pane in `ListDetailLayout` now support titled sections, header actions and items in the folded rail.
- Panel content uses the standard slim primary scrollbar.

## Changes

- `SidePanel` now requires a `containers` array. `ListDetailLayout` now requires `listContainers`; each section needs a title and content. Migrate existing panel content into titled sections.
- Expanded pane titles show by default. Use `showTitle={false}` on `SidePanel` or `listShowTitle={false}` on `ListDetailLayout` when the pane title should be hidden.
- Small windows have less unused inset space, and move/resize guides no longer dim the app.
