# Tessera v0.62.0

This release makes the in-view hook public, so apps can react when an element comes into sight without a hook of their own.

## New

- `useInView` and `InViewOptions` are exported from the primitives path. It reports whether an element is in view. `dwell` waits that many milliseconds in view before it counts, `once` keeps it true after the first sight, and `threshold` and `rootMargin` pass on to the browser's intersection observer. Existing callers are unchanged.
