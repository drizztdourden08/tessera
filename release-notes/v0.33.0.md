# Tessera v0.33.0

Choices can now be switched off with a reason, the window title bar can drop its window buttons for hosts that have none, and a widget in its own window shows the same disabled state as a docked one.

## New

- A settings choice, a radio option, a segment, a chip or a Select option can be disabled with a reason: it is greyed out, cannot be picked, is skipped by the arrow keys, and shows the reason on hover and to screen readers.
- `WindowTitleBar` takes `controls={false}` to hide every window button, close included, for a host such as a phone that keeps the bar but has no windows to manage.
- `Widget` takes `disabled`, with an optional reason, and `onOpenSettings`, so a widget popped into its own window shows the same disabled state as a docked one.

## Changes

- SegmentedControl is now one Tab stop, moved through with the arrow keys, Home and End, like Tabs.
- The disabled message over a docked widget now sits in the middle of what you can see, not in the middle of a long scrolled body.
