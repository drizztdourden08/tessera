# Tessera v0.123.0

RecordCard gives every item of a list the same card.

## Changes

- New composite `RecordCard`. Its header holds, in order, a chevron, an icon, a code, the title with a content slot, and a menu.
- Every header slot is a centred flex box, so TypeMark and BrandMark sit on the centre line with no extra line height.
- Folded, the title sits in the header. Open, it moves to a second row above the body.
- It takes `open`, `defaultOpen` and `onOpenChange`, and a `density` of `row` or `card`.
