# Tessera v0.56.2

This patch keeps dialogs inside the window and lets the repo start its catalogue through the Brock thread commands.

## Fixes

- A dialog now stays inside the window. Its header and actions stay put, and only the body scrolls. CreateRecordDialog uses this in place of its own height cap.
- Dialogs open with a fade only, without scaling, so their buttons no longer shift while they appear. Reduced motion turns the fade off.
- `pnpm tessera launch main none --target storylite` starts the catalogue on port 4400, through Brock's thread commands. A worktree serves on its own port.
