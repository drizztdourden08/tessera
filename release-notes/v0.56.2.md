# Tessera v0.56.2

One paragraph for the people who use Tessera: what this release changes for them.

## Fixes

- The tessera command now runs the Brock thread commands in this repo, so tessera launch main none --target storylite starts the catalogue on port 4400.
- A dialog now stays inside the window: its header and actions stay put and only the body scrolls. The open animation now fades without scaling, so buttons no longer shift.
