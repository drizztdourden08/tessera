# Tessera v0.84.0

This release brings a long round of opt-in options for the Argus Node design. Every default look stays the same, so other apps see no change unless they turn an option on.

## New

- Tabs takes `size="lg"` for 40 px tabs and `selectedTone="neutral"` for an active label in the text colour.
- SegmentedControl and a selectable Tag take `selectedTone="neutral"` for a grey selected fill instead of the accent.
- Tag takes `outlined` and `size="lg"` (24 px). TagPicker takes `pill`. Text takes `size="md"`, a 13 px step.
- DropdownMenu takes `itemSize="roomy"` and an item `kind="select"`, a Select row that keeps the menu open.
- Link takes `tone="info"` and `tone="link"`, the lavender link colour, through the new `--c-link` tokens.
- Markdown takes `smartTimes`, which turns an x between digits into a multiplication sign, and `linkTone`.
- KanbanBoard takes `grip={false}`, `foldable={false}`, `columnHeight="fit"` and `stack` for narrow boards.
- Select, Combobox, TextInput and SearchInput take `width="fit"` or `width="narrow"` (220 px).
- TrackTable takes `onRowClick`, `rowDetail` and `rowTone`. DataTable `rowState` takes `'edge'`, a left bar with no tint.
- InlineEdit takes `look="link"`. WindowHeader takes `stackNarrow`. Disclosure takes `wrapEnd`.
- MarkdownEditor takes `toolbarEnd` and `preview={false}` for a write only editor.
- New `book` icon.

## Fixes

- Callout draws its text in a div, so block children such as a Stack of rows or buttons are valid inside it.
