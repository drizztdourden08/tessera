# Tessera v0.55.0

This release adds five parts any editor needs: a menu that opens where the user right-clicks, an anchor picker, a list that stays fast with thousands of rows, drag selection with a rectangle, and segmented controls that take any icon.

## New

- ContextMenu is a DropdownMenu that opens at the pointer on right-click or long press, and under the focused element with Shift+F10 or the Menu key. It flips to stay in the window. An app can also drive it with `open`, `point` and `onClose`.
- AnchorPicker picks one of nine anchors in a three by three grid, as image editors use to resize a canvas. It has a `dots` and an `arrows` variant and moves with the arrow keys in two dimensions. The `Anchor` type names the nine values.
- VirtualList draws only the rows in view of a very long list. Arrows, Home, End, Page Up and Page Down move focus, and a focused row stays drawn while it holds focus. Its windowing is the `useVirtualWindow` hook, which DataTable now shares.
- `useMarqueeSelect` lets the user drag a rectangle over an area to pick the items inside. Shift adds, Ctrl or Cmd toggles, Escape cancels, and the area scrolls near its edges. `MarqueeBox` draws the rectangle.

## Changes

- The `icon` of a SegmentedControl option takes an icon name or any node, so pixel icons and custom drawings work. The new `SegmentIcon` type names it.
