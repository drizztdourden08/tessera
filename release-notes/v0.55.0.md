# Tessera v0.55.0

One paragraph for the people who use Tessera: what this release changes for them.

## Changes

- New composite ContextMenu: a DropdownMenu that opens at the pointer on right-click or long press, and under the focused element with Shift+F10 or the menu key, flipping to stay in the window; it also takes `open`, `point` and `onClose` to be driven by the app. New composite AnchorPicker: a three by three grid that picks one of nine anchors, with a `dots` or `arrows` variant, arrow keys in two dimensions and the `Anchor` type. SegmentedControl: the `icon` of an icon option is an icon name or any node, so pixel icons and custom nodes work, and the new `SegmentIcon` type names it.
- VirtualList draws only the rows in view of a very long list of equal rows, with the arrow keys, Home, End, Page Up and Page Down, and the windowing it shares with DataTable is now the useVirtualWindow hook. useMarqueeSelect lets the user drag a rectangle over an area to pick the items inside, with Shift to add, Ctrl or Cmd to toggle, Escape to cancel and scroll near the edges, and MarqueeBox draws the rectangle.
