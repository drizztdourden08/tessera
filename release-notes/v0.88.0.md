# Tessera v0.88.0

This release brings most of the parts Bxel's redesign asked for: a shared selection model, virtual grids and lists that select and reorder, a richer colour picker, a project browser set, number fields and new toolbar item kinds. Every new option is opt-in, with one change for every app: disabled menu items now dim like disabled buttons.

## New

- `useSelectionModel` (composites/selection) picks with anchor, toggle, range, all and type ahead. DataTable now uses it and behaves as before.
- VirtualGrid takes `selection`, rectangle ranges by Shift click, marquee cells, and `reorder` with a set drag, an insertion line and a DragGhost.
- VirtualList takes `orientation="horizontal"` and `selection`. `useReorderDrag` moves a whole selected set.
- ColorPicker takes `modes` for HSV, OKLCH and RGB tabs over one value, with gamut clamping, a `name` and a `footer`.
- ColorSwatch takes up to four corner `marks`, `unused`, `mixed`, `focusRing="apart"` and `fill`.
- New ChoiceGrid: one radio group or listbox over a grid of cells, with sections and pick on release. New pixel icons for Bxel.
- New Breadcrumbs, Tile, SplitButton and Navigator.
- FilterBar takes `maxChips` and `parseToken`. Anchored takes `anchorRect` and `boundary`.
- SplitPane takes a `summary` when collapsed. AnchorPicker takes a custom point. Image takes `backdrop="checker"` and `fit="integer"`.
- New NumberField (label scrub, wheel, fine step, presets) and AngleField (a dial with snap). `useWheelStep` is the shared wheel hook.
- TextInput, NumberInput, Select, Checkbox, Slider and ToggleGroup take `mixed` for a multi-selection with different values.
- Toolbar items take menu and slot displays, hold to open, popover panels, badges, named separators, inline options and `keyBadges` for tool rails.

## Changes

- A disabled DropdownMenu or ContextMenu item is drawn at the disabled opacity, the same as a disabled Button, so it reads clearly as unavailable.
