# Tessera v0.43.1

One paragraph for the people who use Tessera: what this release changes for them.

## Fixes

- ItemList takes `maxRows`: the list shows that many rows, whatever their height (a flush picture included), and scrolls the rest, while the title, count, New and filter stay fixed above. The selected row scrolls into view. Without `maxRows` nothing changes.
