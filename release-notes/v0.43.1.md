# Tessera v0.43.1

A list can now cap how many rows it shows, so a long list of saves stays a fixed height and scrolls.

## New

- ItemList takes `maxRows`. The heading, count, New button and filter stay fixed, exactly that many rows show (rows with a picture included), and the rest scroll. The selected row scrolls into view.
