# Tessera v0.128.1

The side navigation pane keeps even margins, and phones show hidden row actions.

## Changes

- ScrollArea takes `gutter="both"`. It reserves scrollbar room on both edges, so the left and right margins match.
- The SideNavLayout scrolling pane uses the both-edge gutter.
- Under the `.platform-mobile` root class, ListItemRow actions, the list name action, Tree hover trails and the InlineEdit pen are always shown. The InlineEdit pen also shows on devices without hover.
