# Tessera v0.30.2

The file the guide writes for an app's part names now works on its own, even in an app that only imports part of Tessera, and it is cleared when an app has no parts left.

## Upgrading

- Run `tessera guide` once to rewrite each parts file. Until you do, `tessera check` reports that the file is out of date.
- MIGRATION.md section 219 describes the change.

## Fixes

- The parts file now starts with its own import of Tessera, so its part names reach TypeScript even in an app that imports only a subpath such as `@drizztdourden08/tessera/composites`.
- When an app has no parts left, the guide writes the file with no names instead of leaving the old list in place.
