# Tessera v0.116.0

This release lets OverflowRow push items to the far right and lets Tree rows take part in the ContentSwap reflow.

## Changes

- An OverflowRow item takes a new `end` flag. That item and every later one sit at the far right of the row, the More button stays before them, and the fold still counts them.
- Tree rows now carry `data-swap-item`, like ListItemRow, so a ContentSwap with the `reflow` effect moves them one after another.
