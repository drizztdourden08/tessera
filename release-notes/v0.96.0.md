# Tessera v0.96.0

This release adds a lead text size, a title font, quiet buttons and solid tags, toned table rows, a new RampStrip for colour ramps, and native drop and spring-open in Tree. Times between digits can now render as a true multiplication sign in Text, Tag and FoldText.

## New

- `Text` takes `font="title"`, Chakra Petch at weight 600, and `size="lead"`, a 15 px size for lead lines. The token `--text-lead` is new.
- `Text`, `Tag` and `FoldText` take `smartTimes`. An `x` between two digits, as in `16x16`, shows as a multiplication sign.
- `Tag` takes `fill="solid"` for a neutral grey chip and `fill="tint"` for the tinted look.
- `FoldText` takes `truncate="path"`. A long path keeps its first folder and its file name and cuts the middle.
- `Button` takes `variant="quiet"`, a button with no fill until hover.
- `Checkbox` takes `boxed`, which draws the box and its label inside a bordered row.
- `SegmentedControl` takes `size="sm-plus"`, segments of 28 px. The type `SegmentSize` is exported.
- `DataTable` takes `headerRules={false}` for plain headers and `rowTone`, which tints a row by status. The type `RowTone` is exported.
- `RampStrip` is a new composite: a row of colour steps to pick from, with `size` sm, md or preview and an optional `numbered` label.
- `LoadError` takes `actions`, a slot for buttons under the message.
- `Tree` takes `onRowAuxClick`, called on a middle click. Rows spring open while a native drag hovers them.
- `CommandPalette` takes `header`, a slot above the search field.
- `PathInput` takes `nativeDrop`, on by default. Turn it off when the page handles file drops itself.
- Two icons are new: `pixel-view-split-link` and `pixel-view-split-actual`.

## Changes

- The knip entries now list only the part folders that exist, so a repo without composites no longer gets a missing folder warning.
