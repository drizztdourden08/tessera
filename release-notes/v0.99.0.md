# Tessera 0.99.0

Long lists stay fast, DynamicInput takes a pasted value and searchable choices, and a few small sizes for Argus.

## New

- The shared listbox of Select, Combobox and DynamicInput choice slots draws only the rows in view once a list holds more than 200 options. A list of thousands opens and scrolls at once, and the keyboard still reaches every row (I-95).
- DynamicInput takes a whole value pasted into any slot. A full code such as ABCD-1234 fills every slot at once (I-96).
- DynamicInput choice slots take `search`, a text box that filters the options as you type, and `free`, which keeps the typed text when no option is picked (I-97).
- DropdownMenu takes size `2xs` on a trigger, and KanbanColumn takes `header`, a node drawn in the column head (I-98).

## Changes

- A click on a choice chip opens its list, and a second click closes it. The list now sits under its chip (I-97).
- TypeMark outline fills the box the tile would take, 16 px at xs and 20 px at sm (I-98).
- `visibleRange` and `renderedIndices` now live in the data tier. They are still exported from the same places (I-95).

## Fixes

- LogPanel scrolls inside a rigid ToolFrame. Its height is set by the frame and not by the rows (I-99).
