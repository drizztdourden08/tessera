# Tessera v0.133.0

The Argus batch: a mark that shows what it is doing, a chat composer, a split drawer, and tidier record cards and Kanban groups.

## New

- `BrandMark` takes `activity`: `idle`, `thinking`, `working` or `talking`. The eyes glow while thinking and working, and the mouth opens and closes while talking. Reduced motion keeps it still.
- `BrandMark` size `h52`, for a 64px header.
- `Composer`: a rounded chat box with a growing input, a send button and a bar slot. Enter sends, Shift+Enter starts a new line.
- `TickerText`: one line that slides back and forth when it is too long, and stops on hover and focus.
- `Textarea` takes `look="bare"`, `autoGrow` and `maxRows`.
- `MarkdownEditor` takes `layout="composer"`.
- `Drawer` takes `look="split"`: the header and the body float as two glass cards.
- `RecordCard` takes `density="compact"` and `end`. `RecordHeader` and `RecordCard` take `chevronOnIcon`.
- `SignalStrip` takes `overflow="scroll"`.
- `KanbanBoard` takes `foldedGroups` and `onFoldedGroupsChange`. A column takes `accent`, which tints its head.
- `ScrollArea` takes `followBehavior`: `smooth` or `instant`.

## Changes

- `ScrollArea` follow mode jumps to the end at once the first time, then follows the content.
- A card mode `RecordHeader` no longer grows, and its last row stays at the bottom of the card.
- `RecordHeader` never wraps. The code ends in an ellipsis and the content slot clips.
- A Kanban group is a closed box with padding, and the column no longer scrolls sideways.
