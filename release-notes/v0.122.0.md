# Tessera v0.122.0

GroupBar brings group by in the FilterBar look.

## Changes

- New composite `GroupBar`. It takes `options`, `value` (ordered ids), `onChange` and `maxLevels`.
- It is empty by default. The Add group button opens a menu of fields, and each pick shows as a removable chip.
- The button and chips match FilterBar in height and look, so the two sit on one centre line.
