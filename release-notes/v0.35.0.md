# Tessera v0.35.0

A screen can now ask for compact controls in one place, and every way an app used to restyle Tessera's insides has a proper option instead, along with a few more icons and small additions.

## New

- DensityScope makes every form control inside it draw at the small size, so a dense editor panel no longer restyles each control by hand. A control's own size still wins.
- Four icons: skull, shovel, tree-deciduous and waves, with `tree` and `water` as shorter names for the last two.
- Button takes `iconEnd` for an icon after the label.
- Toggle and Checkbox take `labelSize` for a smaller label.
- Image takes `fit`, and `pixelated` to draw pixel art sharply; `usePixelArt` tells whether a picture is pixel art.
- DisabledOverlay takes a `tone`, and `placement="top"` to keep its message at the top and in view while the covered area scrolls.
- Disclosure takes `bodyClassName`.
- WindowHeader and DialogShell take `titleWrap` so a long title wraps instead of being cut short.
- SegmentedControl takes `className`, and a log kind can be shown in bold.
- `IDENTITY_PATH` can also be imported from `/data`.

## Upgrading

- The class `dropdown-trigger__end` is now `btn__icon--end`, and `hero__art--pixelated` is gone; RENAMES.json maps both, along with `MediaViewerPixels`, now `ImagePixelated` in `/primitives`.
- MIGRATION.md sections 226 to 228 describe each change, and section 227 lists, for each restyling an app may have done, what to use now.
