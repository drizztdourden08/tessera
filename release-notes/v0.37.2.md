# Tessera v0.37.2

An app can now hide the title bar's View sub-menu or move it anywhere in its main menu, so every main menu entry can be hidden, renamed or moved.

## New

- WindowTitleBar takes `view`: `false` hides the View sub-menu, and `{ group, position }` places it in a given menu group at a given position (`'start'`, `'end'` or an index). Without it, the menu is the same as before.

## Upgrading

- With `view={false}`, a narrow window has no way to reach the pin and full screen buttons, since they move into the View sub-menu at those widths.
- MIGRATION.md section 242 describes the option.
