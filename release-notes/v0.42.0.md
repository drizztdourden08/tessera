# Tessera v0.42.0

Saved dock layouts from before `makeRoom` existed no longer let the main view run under their panels. Log kinds can take any colour, counts can hide a zero, and a pixel-art wordmark stays sharp on the splash.

## New

- A LogPanel kind takes a tag tint or any hex colour as its tone, lifted until it reads on the dark ground, and `uppercase` for messages in capitals.
- Badge, Tabs, Card, SectionHeader and HeaderAnchorNav take `hideZero`, so a count of 0 shows nothing.
- Splash takes `wordmarkPixelated` (`true`, `false` or `'auto'`, as on Image), and the static kit has `ts-wordmark--pixelated`, so a pixel-art wordmark scales up sharp.

## Changes

- A wide wordmark on the splash no longer sits in a 48 px box with empty space above and below.

## Upgrading

- A smooth wordmark picture less than 48 px high now draws at its own height; draw such wordmarks at least 48 px high.
- MIGRATION.md sections 258 and 259 describe each change.

## Fixes

- A docked pane saved without `makeRoom` now makes room, in saved layouts and in `migrateLayout`, so the main view sits between the panels instead of under them.
- A tall floating pane on one side no longer stretches the main view under the panes that make room on the other sides.
