# Tessera v0.44.0

A speech bubble joins Tessera, so a mascot or a guided tour can point at what it explains.

## New

- SpeechBubble is a box with a tail on any side, or none, in the surface colour with an optional tone, rounded corners and a soft shadow. The guided tour's bubble now draws through it.
- `useReducedMotion` is public.
