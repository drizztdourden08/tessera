# Tessera v0.114.0

This release lets an app tell the user when DropZone refuses a file.

## Changes

- DropZone takes a new `onReject` prop. It is called with the files that `accept` refused, so the app can say why, for example "Only PNG and SVG" through `status`.
- DropZone now has a usage file and its own answer in the guide, for files dropped or pasted onto an area.
