# Tessera v0.107.1

The prebuilt token files catch up with their sources.

## Changes

- `tokens.css` now holds the ChronoType font face and `--font-chrono`. Apps that load only `tokens.css` get the font instead of a fallback.
- `tokens.json` and `splash-tokens.css` carry the darker ChronoKi surfaces from 0.103.0.
- `--font-chrono` is a typography token now, so it sits beside `--font-mono`.
- `pnpm lint` fails when `tokens.css`, `tokens.json` or `splash-tokens.css` no longer match their sources. Run `pnpm tokens` to bring them up to date.
