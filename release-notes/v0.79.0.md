# Tessera v0.79.0

This release redraws the Archipelia mark as a clean vector, adds an xxl mark size, and adds SectionTimeline, a vertical anchor nav for long pages.

## Changes

- The Archipelia mark is redrawn as a clean vector of true circles and straight bars, with the same look, so its edges stay smooth at any size and every brand file is regenerated from it. BrandMark, Logo, Logo.Combined, Mascot and AnimatedMascot take a new `xxl` size, the 256 px token `--brand-mark-xxl`, for a large mark such as an empty start page.
- New SectionTimeline composite: a vertical, grouped list of section links with `aria-current="location"` on the active one, `onJump`, and a decorative progress line with an idle or hidden `state`. The line fills from a CSS scroll timeline (`timeline="scroll"` or a named view timeline) and jumps to `progress` or the active section without scroll-driven animation or with reduced motion.
