# Tessera v0.47.0

One paragraph for the people who use Tessera: what this release changes for them.

## Changes

- Stepper can draw an editable ladder: a step takes its own `state`, `media` and a struck-through label, and the Stepper takes `selectMode="toggle"`, `labelPlacement`, `labelLines`, `dotVariant="ring"`, `stepWidth`, `mediaSize`, `scroll` and a `neutral` tone, so an app needs no Tessera selectors.
