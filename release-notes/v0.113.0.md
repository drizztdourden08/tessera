# Tessera v0.113.0

This release lets a pinned OverflowRow item adapt when the row is too narrow even for the pinned items.

## Changes

- An OverflowRow item `node` may now be a function of `{ tight }`. The flag is true when every unpinned item is folded and the pinned items still overflow, so a pinned Tabs can switch to `iconOnly`.
- The new `OverflowRowNodeState` type is exported with the navigation exports.
