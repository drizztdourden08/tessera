# Tessera v0.129.0

A chat transcript for the Argus Overlord chat, and a scroll area that stays at the newest row.

## New

- ChatTranscript lists chat messages in rows by speaker. Each message folds its tool calls into one closed section that names the count and shows when a tool is running or failed. A tool with detail opens its own section. It stays at the newest message as messages arrive.

## Changes

- ScrollArea takes follow. It keeps the area at the bottom as the content grows, while the reader is at the bottom. Scrolling up stops it; scrolling back down resumes it.
- LogPanel now reads its bottom check from ScrollArea. Nothing changes for its users.
