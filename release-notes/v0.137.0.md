# Tessera v0.137.0

The chat look for Argus.

## Changes

- `Composer` starts as one row and grows to `maxRows`. The send button sits inside the box, at the end corner. The foot row shows only when a `bar` is set.
- `MarkdownEditor` with `layout="composer"` works the same way. Its send button floats inside the box, and the foot row shows only for actions or a counter.
- `ChatTranscript` puts user messages in a bubble on the end side, with the time under the bubble. It renders the last 30 rows and loads earlier ones as you scroll up, keeping your place. New rows slide in.
- `BrandMark` floats with a slow bob while thinking or working. Its eyes light up one after another in a sweep.
- The `RecordHeader` usage line now names the sizes that fit: avatar `xs`, menu button `xs`.

## New

- `Text` takes `dots`. It adds a moving ellipsis to a busy label, such as "Thinking".

All motion stops when the system asks for reduced motion.
