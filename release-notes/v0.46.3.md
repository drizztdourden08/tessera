# Tessera v0.46.3

The list pane and the detail pane of ListDetailLayout no longer touch. A small gap from one spacing token now separates them, so the dashed list border and the detail surface read as two panes.

## Fixes

- Add the standard small gap between the list pane and the detail pane of ListDetailLayout, from one spacing token, in pixel and ratio layouts.
- Keep the resize handle and the fold buttons centered on the list border.
