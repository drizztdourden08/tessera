# Tessera v0.115.0

This release stops a closed Drawer from widening the page and stops a focus ring from showing when a screen opens.

## Changes

- Drawer now mounts through Portal in the modal layer, like DialogShell. A glass card around it no longer becomes its containing block, and its root clips the closed panel, so it adds no scroll width.
- A dialog, drawer, screen or floating prompt with no `initialFocusRef` now focuses its title or its own container on open, not its first control. No control shows a focus ring until the user presses Tab.
- A dialog that passes `initialFocusRef` still focuses that control, so a form dialog still starts in its field.
