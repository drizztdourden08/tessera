# Tessera v0.95.0

This release adds icon-only split buttons, status badges and a roomy row size to Tree, and grid rows that grow to fit their tiles. Toolbars drop their key badges, and the slim scrollbar thumb gets round ends.

## New

- `SplitButton` takes `iconOnly` and `shortcut`. With an `icon`, `iconOnly` draws the main button as the icon alone, and a tooltip shows the label and the shortcut. The label still names the button for assistive tools.
- `Tree` takes `renderBadges`, a row slot between the label and the trail that is always shown. With `trail="hover"`, status badges stay visible while actions wait for hover, focus or a picked row.
- `Tree` takes `rowSize="roomy"`, rows of 48 px for a 40 px thumbnail or two lines in a row.
- The Tree ref handle has `scrollToTop()`, which scrolls the tree back to its first row. Call it after a filter change.
- `VirtualGrid` takes `rowHeight="measured"`, so each row of tiles is as tall as its tallest tile. Keys, paging, the marquee and reorder follow the measured rows. The type `VirtualGridRowHeight` is exported.

## Changes

- The slim `ScrollArea` thumb has round ends, at rest, under the pointer and while dragged.
- `trail="hover"` on Tree now hides only `renderTrail`, and the row no longer shifts when the actions show.

## Upgrading

- Toolbar no longer takes `keyBadges`. Shortcuts show only in tooltips. Remove the prop where you pass it.
