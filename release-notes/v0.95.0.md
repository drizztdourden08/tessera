# Tessera v0.95.0

This release adds the PointerPalette and RampStrip composites, a lead text size and a title font, quiet buttons, solid and tint tags, toned table rows, icon-only split buttons, and many Tree and VirtualGrid options. Toolbars drop their key badges, and the slim scrollbar thumb gets round ends.

## New

- `PointerPalette` is a new composite: a sectioned grid of icon cells opened at a point. A tap opens it for clicks and keys. With `holding` set, letting go over a cell picks it, even when holding turns false before any pointer release. Arrows move across sections, Enter picks, Escape closes and focus returns. Each cell can show its key.
- `RampStrip` is a new composite: a row of colour swatches for one ramp, with a caption on each step and one step picked. A large `preview` size stretches the steps over the full width. Left, Right, Home and End move between steps and pick them. Steps can be `unused` or `disabled`.
- `Text` takes `font="title"`, which draws any size in the title face at weight 600, and `size="lead"`, a 15 px step between the base and large sizes. The token `--text-lead` is new.
- `Text`, `Tag` and `FoldText` take `smartTimes`. An x between two digits shows as a multiplication sign. Markdown shares the same logic.
- `Tag` takes `onClick` without `href` and renders a button.
- `Tag` takes `fill="solid"`, a grey chip for the neutral colour, and `fill="tint"`, a tone edge with a tint of the tone as the fill.
- `Tag` takes `edge`: `solid` (the default) or `dashed`, a dashed border of the same width that works with every fill.
- `FoldText` takes `truncate="path"`. It keeps the last path segment whole and cuts the middle of what comes before it.
- `Button` takes `variant="quiet"`, a grey button with grey text, a subtle border and a fill one step above the surface. It suits minor actions such as Copy.
- `Checkbox` takes `boxed`. It draws the box and its label inside a small bordered box that turns green when checked, for filter toggles in a toolbar.
- `SegmentedControl` takes `size="sm-plus"`, a step between `sm` and `md`. The tokens `--control-h-sm-plus` and `--control-pad-sm-plus` are new, and `SegmentSize` is exported.
- `SplitButton` takes `iconOnly` and `shortcut`. With an `icon`, `iconOnly` draws the main button as the icon alone, and a tooltip shows the label and the shortcut. The label still names the button for assistive tools. `shortcut` takes keys such as `F3` and adds the same tooltip to a text button. Without the two props nothing changes.
- `DataTable` takes `rowTone(row)`, which gives the left edge of a row one of the Status tones, with or without `rowState`. It also takes `headerRules`, which when false drops the vertical rules between the header cells. The rule still shows under the pointer so a column stays easy to resize.
- `LogPanel` takes `minRows`, so the list never gets shorter than that many lines. The default is 3 with `height="fill"`, so a small widget no longer collapses it.
- `LoadError` takes `actions`, nodes drawn beside the Retry button, such as a Reveal button. The app builds the button and handles its click.
- `CommandPalette` takes `header`, any node drawn above the input, such as a row of Tag for scope chips.
- `PathInput` takes `nativeDrop`, true by default. Set it to false when the app handles file drops itself. The drop then reaches the app first and no error flashes for a path the app has not vetted yet.
- `Tree` takes `renderBadges`, a row slot between the label and the trail that is always shown. Status badges stay visible while actions wait for hover, focus or a picked row.
- `Tree` takes `rowSize="roomy"`, rows of 48 px for a 40 px thumbnail or two lines in a row, and `rowSize="tall"`, rows of 40 px between normal and roomy. The row height is measured from the drawn row, so the drawn window, drag drop and focus follow it.
- The Tree ref handle has `scrollToTop()`, which scrolls the tree back to its first row. `scrollToKey` does nothing for a key the filter hides, so call `scrollToTop` after a filter change.
- `Tree` takes `onRowAuxClick(key, event)`, called with the row key on a middle click.
- `VirtualGrid` takes `rowHeight`: `'fixed'` (the default, unchanged) or `'measured'`. With `'measured'` each row of tiles is as tall as its tallest tile, so cards with different amounts of content no longer overflow into the next row or section. `tileHeight` and `tileSize` become the least height and the guess for rows not drawn yet. The grid keeps the scroll steady when a row above the view changes height. Keys, paging, scroll to index, marquee rects and reorder drop follow the measured rows. The type `VirtualGridRowHeight` is exported.
- New icons: `gavel` and `signpost`, and the pixel icons `pixel-view-split-link` (two halves joined by a chain, so they pan and zoom together) and `pixel-view-split-actual` (a 1 in each half, for the view at 100 percent). The split icons appear in the pixel icon gallery.
- The type `TagEdge` is exported from the package root.

## Changes

- The Bxel icon mark now follows the Bxel app icon: the pixel B with its coral corner pixel, the trail of fading squares to its left, and the mist sparkle at top right, framed on the tile. The tile stays one flat night colour.
- `Tag` with `fill="tint"` draws a soft grey tint with a grey edge on the neutral colour.
- `Tree` with `trail="hover"` now hides only `renderTrail`. The row does not shift when the actions show.
- A native drag from another widget held over a closed `Tree` folder now opens it after the spring delay, 600 ms by default, with or without `reorder`.
- The slim `ScrollArea` thumb has rounded ends, at rest, under the pointer and while dragged, on vertical and horizontal bars. Its length, place and colours are unchanged.

## Upgrading

- `Toolbar` no longer takes `keyBadges`. Shortcuts show only in tooltips, never on the button. Remove the prop where you pass it.

## Fixes

- `useMarqueeSelect` no longer starts a drag on a button, a field, a link or a column header unless `canStart` says so.
