# Tessera v0.69.0

One paragraph for the people who use Tessera: what this release changes for them.

## Changes

- Adds the Bxel animation file type `.bxanim` with a film strip glyph, and the `pixel-animation` icon it is drawn from.
- DataTable takes `renderCell(row, path)` to draw a cell itself, falling back to the schema when it returns undefined, `rowState(row)` to mark a row active, pending, error or muted, and `rowHeight`, a size token, for taller rows. It also takes `sort` with `onSortChange` and `expanded` with `onExpandedChange` to let the app own the sort and the open groups. The new `groupUid` export builds the group ids that `expanded` holds.

## Fixes

- A menu opened from a side toolbar now aligns its top edge with the button and grows down, flipping up only when it does not fit below, instead of always growing from the roomier side of the screen.
