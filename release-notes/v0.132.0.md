# Tessera v0.132.0

Key and mouse names now come from strings, so a translated app shows them in its own language.

## New

- The `keys` strings group: a spoken name for every key, a cap label where the key has one, and the mouse button names.

## Changes

- `KEY_SPECS` and `MOUSE_SPECS` no longer carry name text. `keyFace` and `tourLabel` take the `keys` strings.
- `aria-keyshortcuts` uses the standard key values, like `ArrowUp` and `PageDown`.
