# Tessera v0.119.0

A fix for crowded header rows, asked for by Argus.

## Changes

- OverflowRow items take a shrink flag for a pinned item that scrolls itself, such as Tabs.
- When icon-only tabs are still too wide, the tabs narrow and scroll sideways, and end items such as a settings button stay in the row.
- The OverflowRow story has a new variant that shows tabs scrolling in a narrow row.
