# Tessera v0.127.0

ContentSwap can swap with no overlap.

## Changes

- ContentSwap takes sequence, overlap by default or out-in. In out-in the old content leaves fully before the new content shows, so the two are never visible together.
- In out-in the box keeps the old height until the hand-over, and a second swap during the exit ends on the newest content.
- Reduced motion still swaps instantly in both sequences.
- ContentSwap has a catalogue story with both sequences.
