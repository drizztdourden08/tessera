# Tessera v0.37.4

The pin and full screen rows the title bar adds to its main menu on a narrow window can now be renamed, moved or hidden one by one, so every main menu entry can be configured.

## New

- WindowTitleBar takes `tucked`, with `pin` and `fullscreen` entries that each take `label`, `activeLabel`, `group`, `position` and `hidden`. A label changes only that menu row, not the bar button or the View sub-menu. Without `tucked`, the menu is the same as before.

## Upgrading

- A tucked row with `hidden: true` can't be reached on a narrow window, since the bar still tucks its button away.
- MIGRATION.md section 244 describes the option.
