# Tessera v0.105.0

ChronoKi's app icon has a strong black outline that holds at taskbar sizes.

## Changes

- BrandInfo takes `iconOutline`, a colour. The icon build draws it around the app icon, about 3.5 percent of the icon wide and never under 1.25 px, so it stays clear at 16, 24, 32 and 48 px.
- ChronoKi sets it to black: the svg, png ladder, ico, maskable icon and splash show the C with a black outline.
