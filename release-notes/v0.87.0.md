# Tessera v0.87.0

This release brings the toolbar layout fields Brock needs for the Bxel redesign, more Argus options, and a ListDetailLayout fix. Every new option is opt-in.

## New

- ToolbarLayout takes `items`, the item ids hidden in each toolbar, and `columns`, 1, 2 or auto per toolbar. `setToolbarItems` and `setToolbarColumns` update them, and old layouts load unchanged.
- Toolbar takes `columns` for a vertical bar, `priority` on an item so the lowest fold into More first, `hiddenItems`, and `onContextMenu` on an item or on the bar.
- The Argus mark draws in `currentColor`, so the app sets its colour. Its favicons are black on light grounds and white on dark.
- Card and Flex take `container`, so a `width="narrow-fill"` field inside has a box to measure.
- A TrackTable column takes `hideBelow` (1280 down to 480 px), and a hidden column leaves no gap.
- FoldText takes `hug` with `truncate="middle"`, so a button can sit right after the text.
- Drawer takes `headerActionsRow="eyebrow"` to put its tools in the id and tag row.

## Fixes

- ListDetailLayout takes the full width of its parent, so a parent that sizes children to their content no longer shrinks it into the stacked layout.
