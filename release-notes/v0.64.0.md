# Tessera v0.64.0

This release starts the new toolbar dock: toolbars sit in a visible bar, can share a lane, and have resize handles that push their neighbours. Widget panels get the same pushing dividers and can take a corner. It also fixes the compact card tooltip and the SNES select and start glyphs. Toolbar corner take and drop placement come in the next release.

## New

- Each docked toolbar has a thin resize handle at both ends. Dragging one pushes the neighbouring toolbars along, with a live preview, arrow keys and an announcement.
- ToolbarDock draws its lanes on a five by five grid from the stored corners. A bar can cover part of a lane, and a rail can run under a top bar or the full height.
- A DockLayout panel can take a corner from its neighbour or give it back, by dragging its corner handle or with the arrow keys. This flows through the new `take-corner` edit in `applyEdit`.

## Changes

- ToolbarLayout is now v2. Each toolbar has a start and a size along its lane, a lane holds several toolbars, and `corners` records which side claims each corner. `migrateToolbarLayout` upgrades a saved v1 layout, so stores that already pass saved layouts through it need no script. Read toolbar ids with the new `toolbarIdsOf(layout, side)` instead of `layout.sides`.
- New with the v2 layout: `normalizeCorners`, `placeToolbar`, `MAX_LANES` and `MIN_SHARE`. `MAX_PER_SIDE` stays one release as a deprecated alias of `MAX_LANES`.
- Dragging or keying a DockLayout divider now pushes. When the neighbour reaches its minimum, the next panel in the split shrinks, and the divider range covers the whole chain.
- The controller anchors and their types moved to `@drizztdourden08/brock-input`. `ControllerSilhouette`, its paths, view box and variants stay in Tessera. See MIGRATION 276.

## Fixes

- Docked toolbars now sit in a bar with a surface, a thin border and a small radius.
- A Tooltip around a detail in a compact ItemCard now shrinks and ends in an ellipsis like a plain detail.
- The SNES select and start glyphs now draw only the pill, centred like the other button glyphs.
