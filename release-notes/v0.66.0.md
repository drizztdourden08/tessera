# Tessera v0.66.0

This release answers a round of app requests. Widgets can be sized by weight, and the corner handles are easier to hit. Settings rows, the side menu and grid tiles get layout options. A table fills a non-scrolling list pane. Slim scrollbars and tooltips behave better while scrolling.

## New

- WidgetDefinition takes `dockWeight`. Widgets that share an edge are sized by weight instead of evenly, and every child of the edge keeps its weight when another one joins. `defaultDockedSize` now also resizes the column a widget joins.
- SideNav takes `config.top`: pages that sit under Home in one top block, with a single divider after it. WorkspaceScreen passes `top` through.
- VirtualGrid takes `renderTile(item, index, cell)`. The app spreads `cell` on its tile, so an interactive tile is the grid cell and the only focus target. `renderItem` still works as before.
- PanelContainer takes `fill`. ListDetailLayout sets it when `listScroll` is false, so a DataTable in the list pane fills it and scrolls on its own.

## Changes

- FormRow shows its reset button right after the name, and only when `changed`. A hidden reset leaves no gap, and the control column is end-aligned so every control in a list shares one right edge.
- A slim ScrollArea reserves its own end gutter, so opaque children such as cards no longer cover the thumb. Listbox lists gain the same gutter.

## Fixes

- DockLayout corner handles keep a thin line but have a 24 px hit area that starts below the widget title bar, so they no longer crowd its buttons.
- Tooltip no longer opens when content scrolls under a still pointer, and a hover Tooltip closes on any scroll. Focus still opens it as before.
