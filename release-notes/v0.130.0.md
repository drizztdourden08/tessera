# Tessera v0.130.0

Fields read with more depth, and the inline drop zone shows its status.

## New

- Token `--c-field`: the field background, one step off the surface.
- Token `--c-placeholder`: a brighter muted tone for placeholder text.

## Changes

- Text inputs, selects, textareas, Combobox, NumberInput, TagInput and DynamicInput sit on `--c-field`.
- Every placeholder is italic in `--c-placeholder`.
- DropZone `variant="inline"` shows `status.message` after its label.
