# Tessera v0.118.0

A new layout primitive asked for by Argus.

## Changes

- AsideLayout takes main and aside and places the aside at the start or end of the main area.
- The aside width is a token: sm, md or lg, written as new aside width tokens in the scale.
- The aside shows only when the layout's own width reaches the breakpoint, and onAsideChange reports each change.
