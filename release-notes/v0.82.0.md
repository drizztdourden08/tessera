# Tessera v0.82.0

This release answers the next round of Argus, Archipelia and Brock requests. It adds a flat track table, seats for a lobby, a record look for Drawer, a sublabel in widget titles, and async control over Wizard.

## New

- Status takes `dotSize="lg"` for an 8 px dot and `halo` for a soft ring in its tone. Tag takes `dot` to lead its label with a dot.
- IconButton `tone` takes `info` and `accent`, beside `danger`.
- Card takes `header`, any content for the header row in place of the title, subtitle and actions.
- New TrackTable: a flat table whose columns take `fr` shares of the width. A column with `drop` 1, 2 or 3 hides as the table narrows.
- Drawer takes `look="record"`: header chips show as written and the title is plain text in sentence case.
- KanbanBoard takes `cardEdgeTone(card)`, which draws a coloured edge on the cards it returns a tone for.
- DocumentTabs takes a `status` on a tab: a phase dot before the title, with its label for screen readers.
- New SeatCard and SeatGrid lay out the seats of a lobby. A seat is filled, needs attention, is empty, or is a dashed button to add one.
- A widget and a PanelContainer take a `sublabel`, a muted label after the title. It shrinks first, and a clipped title shows in full in a tooltip.
- WizardDialog takes a `size` from `md` to `xl`; the default stays 768 px. Wizard takes `busy` to hold its buttons while the app works, and `wizard.goTo(id, { force: true })` moves on when that work is done.
