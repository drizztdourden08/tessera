# Tessera v0.58.0

This release gives Bxel's documents their own file icons, lets a pattern field own its character rules and validation, and adds a windowed tile grid. Toolbars can open menus on a click, show two shortcuts per tool and lay out as a labelled list.

## New

- File type icons for Bxel's sprite, sheet, palette, tileset, tilemap and project files, in `brand/bxel/filetypes/<extension>/` with svg, ico, icns and PNGs from 16 to 512 px. `pnpm icons` writes them. The glyphs are also icons: `pixel-sprite`, `pixel-tilemap` and `pixel-project`.
- VirtualGrid draws a windowed grid of equal tiles, such as sprite thumbnails. Columns follow the width, the tile size is a token, and the arrow keys move in two dimensions.

## Changes

- DynamicInput text slots take `chars`, their own set of allowed characters. A slot or the pattern takes `aliases`, which map typed and pasted characters before the check, for example I and L to 1. A slot or the pattern takes `validate`, which marks the field invalid and shows the message under it. The `invalid` prop still wins.
- Toolbar items take `openOn: 'click'` to open their menu on a press. A `shortcut` can be a list of labelled shortcuts, shown as one row each in the hint. `layout: 'list'` draws the toolbar as rows with icon, name, description and shortcut, for a wide panel.
- VirtualList takes `rowHeight`, a size token, for rows of its own height.
- Checkbox takes a `tooltip` and passes `title` to its input.
