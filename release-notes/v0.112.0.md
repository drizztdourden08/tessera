# Tessera v0.112.0

This release adds a folding row, a reflow motion and a send button for the Markdown editor, and centres icons in rows.

## Changes

- OverflowRow is a new navigation composite. It keeps as many items as fit on one line and folds the rest into a More menu, by priority, with pinned items always shown.
- ContentSwap takes a new `reflow` effect. Items marked with `data-swap-item` slide into their new place one after another, and KanbanCard, ListItemRow and DataTable rows carry the mark.
- MarkdownEditor takes a new `submitLabel` prop. With `onSubmit` set, it shows its own primary send button with the Enter shortcut in a tooltip, so an app no longer adds one in `actions`.
- The MarkdownEditor writing area and preview now sit on the sunken surface, and the toolbar keeps its plain border.
- Icons now centre vertically next to text, and a Flex row centres its children by default. Several composite rows, from SettingsRow to Rating, now centre their content too.
