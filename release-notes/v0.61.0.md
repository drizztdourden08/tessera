# Tessera v0.61.0

This release makes secondary text readable everywhere and fixes six accessibility gaps found in an app audit. Rows can keep a fixed height with the full description in a hint, cards get a compact density for long catalogues, and the status bar takes its own actions.

## New

- ItemCard takes `density="compact"` for one row of about 56 px per item: a 32 px tile tinted by `mediaTone` beside the title (`mediaSize="sm"`), one secondary line and up to three icon actions. An action with `iconOnly` draws as an icon button whose label is its name and its tooltip.
- StatusBar takes `actions`: icon buttons with tooltips at the end of the bar, inside its own border and surface.
- FormRow and SettingsRow take `descriptionOverflow="hint"`. The description clamps to its lines and never shows More; when it is cut, an info mark beside it shows the full text in a tooltip.

## Changes

- Faint and muted text reach at least 4.5:1 on the main ground in every palette, and faint stays under muted under dim. The old faint grey is now `--c-text-disabled`, for disabled text only. Muted text looks slightly brighter than before.
- The Brock palette grey lifts slightly so its faint text also reaches 4.5:1 on its surface. Brock's surfaces keep their old grey through the `--p-surface` seed, so they and the status colours do not move.

## Fixes

- DocumentTabs keeps each close button out of its tablist, so the tablist owns only tabs.
- Stepper names each step with its visible label first.
- CollapseToggle never draws under the 24 px minimum target.
- ColorSwatch focus shows on any swatch colour.
- Toast stops its exit animation under reduced motion.
